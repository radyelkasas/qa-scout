# Changelog

## 1.0.0 — 2026-10-14
First public release by Rady Elkasas (https://radyelkasas.com/).
- Setup page with drag & drop / paste import (config, URL lists, sitemap, accounts, workflows), presets, reachability check, sitemap discovery, export.
- Visible recorded driver: per-page sessions & videos, account logins, live `page` proxy, cursor overlay, pacing.
- Helpers for real-world UIs: comboboxes, hidden radios, number fields, toasts, modals, downloads, request capture.
- In-app page discovery (`H.discover`) from navigation menus.
- Page audit: clipped content, unlabeled/mouse-only/nested controls, stacked dialogs, floating overlaps, untranslated text, raw i18n keys, low contrast, broken images, Arabic spelling pack.
- Findings with framed + labelled screenshots, network evidence, retractions; steps/pass/not-tested/flow logs.
- Reports: per-page Markdown, interconnections, backend, HTML dashboard; English & Arabic.
